## [4.27.3] - 2026-08-08

### Added

- Added opt-in native parallel tool execution for independent function-tool batches, with stable tool identities, explicit per-tool allowlists, bounded concurrency, ordered result aggregation, and cancellation propagation.
- Added Dashboard controls and scoped API endpoints for enabling parallel execution globally or for an individual tool, including eligibility and blocking-reason metadata.
- Added per-MCP-server concurrency limits, retaining serial execution by default.
- Added readable QQ system-face context for OneBot v11 and NapCat LLM requests, including quoted, forwarded, and group-chat context, while preserving original message components and outbound face delivery.

### Changed

- Preserved every async-generator yield through permission-guarded tools and the function-tool executor.
- Added permission revalidation immediately before parallel execution, lifecycle hook coverage for each call, sanitized model-visible failures, and broader MCP result normalization.
- Reworked the local Docker deployment into separate `dev` and `runtime` stages, with pinned base images and Compose health checks.
- Added the `ASTRBOT_FEATURES` build argument for selecting `full`, `minimal`, or comma-separated runtime groups for browser, document, media, OCR, font, Node.js, and Docker tooling.
- Kept the Dashboard listener at `0.0.0.0` inside Compose while binding published host ports to loopback by default, and documented the explicit remote-access override.

### Maintenance

- Added regression tests, bilingual function-calling documentation, OpenAPI definitions, and generated Dashboard API clients for native parallel tool execution.
- Removed the legacy `compose-with-shipyard.yml`; the maintained Compose files build this checkout locally and the NapCat image reference is pinned.

## 中文

### 新增

- 为相互独立的函数工具调用批次新增可选的原生并行执行，支持稳定工具标识、逐工具显式 allowlist、有界并发、有序结果聚合和取消传播。
- 为 Dashboard 新增全局及单工具并行开关和对应权限范围 API，并展示工具是否适合并行及阻止原因。
- 新增按 MCP Server 配置的并发上限，默认仍保持串行执行。
- 为 OneBot v11 与 NapCat 的 LLM 请求新增可读的 QQ 系统表情上下文，覆盖引用、转发与群聊上下文，同时保留原始消息组件和出站表情发送行为。

### 变更

- 权限包装工具和函数工具执行器现在会保留异步生成器产生的全部结果。
- 并行执行前增加即时权限复核，为每次调用覆盖生命周期 Hook，并对模型可见错误进行脱敏，同时扩展 MCP 结果归一化处理。
- 将本地 Docker 部署重构为独立的 `dev` 和 `runtime` 阶段，并固定基础镜像，同时为 Compose 服务增加健康检查。
- 新增 `ASTRBOT_FEATURES` 构建参数，可选择 `full`、`minimal` 或以逗号分隔的浏览器、文档、媒体、OCR、字体、Node.js 和 Docker 运行时功能组。
- Compose 内的 Dashboard 继续监听 `0.0.0.0`，宿主机发布端口默认绑定环回地址，并补充显式远程访问配置说明。

### 维护

- 增加原生并行工具调用的回归测试、双语函数调用文档、OpenAPI 定义及 Dashboard 生成客户端。
- 删除旧的 `compose-with-shipyard.yml`；维护中的 Compose 文件从当前 checkout 本地构建，NapCat 镜像引用已固定。
