## [4.27.3] - 2026-08-13

### Added

- Added effective AstrBot time to settings and made cron jobs inherit the configured timezone. (#9579, #9581)
- Expanded WebChat drag-and-drop uploads to the whole chat area. (#9564)
- Added one-click restoration of plugin configuration defaults. (#9599)
- Added PowerShell 7 support for the Windows local shell. (#9622)
- Added download-count sorting to the plugin marketplace. (#9570)
- Added chunked file uploads for QQ Official to support large files more reliably. (#9646)
- Added opt-in native parallel tool execution, per-tool eligibility metadata, and per-MCP-server concurrency limits.
- Added readable QQ system-face context for OneBot v11 and NapCat LLM requests.

### Changed

- Migrated configuration preference access to asynchronous, non-blocking paths, reducing the risk of freezes and deadlocks. (#9582, #9584, #9649)
- Used favicons as the default plugin icon and improved dark-theme text contrast. (#9547, #9643)
- Preserved every async-generator yield through permission-guarded tools and the function-tool executor.
- Added permission revalidation immediately before parallel execution, lifecycle hook coverage for each call, sanitized model-visible failures, and broader MCP result normalization.
- Reworked local Docker deployment into separate `dev` and `runtime` stages with pinned base images, Compose health checks, and selectable `ASTRBOT_FEATURES` runtime groups.
- Preserved the fork's source-build Compose contract, Python 3.14 baseline, and current Dashboard/API architecture.

### Fixed

- Stabilized knowledge-base search, distinguished loading failures from empty results, restored complete retrieval results, and added UUID fallback when resolving knowledge bases by name. (#9577, #9578, #9618, #9636)
- Refreshed in-memory provider configuration after deletion and synchronized plugin Skill state across the Dashboard. (#9568, #9596)
- Prevented transient project sessions from appearing in ChatUI and restored missing WebChat sessions. (#9587, #9607)
- Sanitized MCP tool names for LLM APIs and treated empty configuration schemas as having no configurable items. (#9534, #9619)
- Warned when an explicitly configured WebUI distribution is stale. (#9518)
- Recorded agent end times before publishing statistics and cancelled stopped agent runs immediately. (#9597, #9602)
- Used static thumbnails for animated Telegram stickers and converted Telegram video notes into video components. (#9610, #9627)
- Propagated QQ media upload failures instead of silently continuing. (#9644)

### Fork Changes

- Redesigned Dashboard long-term memory management as a responsive, theme-aware data view with complete filtering, accessible actions, loading and empty states, and a simplified route hierarchy.
- Added Dashboard controls and scoped APIs for native parallel tool execution, with permission revalidation, bounded concurrency, ordered results, and cancellation propagation.
- Added regression coverage, bilingual function-calling documentation, OpenAPI definitions, and generated Dashboard API clients for native parallel tool execution.
- Kept Compose host port publication on loopback by default while documenting the explicit remote-access override, and removed the obsolete `compose-with-shipyard.yml`.

### Maintenance

- Updated grouped GitHub Actions dependencies, improved pipeline scheduler typing, and stabilized OpenAI HTTP client tests. (#9620, #9621)
- Performed a breaking dependency refresh across Python, root npm, Dashboard, and Docs; aligned the Node.js, npm, and pnpm toolchain declarations and refreshed every authoritative lockfile.
- Updated OpenAI Chat Completions, Responses, Embedding, and TTS providers for OpenAI 3.0's `httpx2` transport, preserving proxy support and connection-error handling.

### Fork Deviations

- Upstream's passwordless AstrBot Desktop sessions (#9585) are not included because this source-build fork does not ship that desktop authentication surface.
- Upstream release wording and upstream-only artifact links are not copied verbatim; this changelog describes the features present in the fork.

## 中文

### 新增

- 在设置中展示 AstrBot 的实际生效时间，并使定时任务继承已配置的时区。 (#9579, #9581)
- 将 WebChat 拖放上传区域扩展至整个聊天区域。 (#9564)
- 新增一键恢复插件配置默认值的功能。 (#9599)
- Windows 本地 Shell 新增 PowerShell 7 支持。 (#9622)
- 插件市场新增按下载量排序。 (#9570)
- QQ 官方机器人新增分片文件上传，提升大文件发送可靠性。 (#9646)
- 新增可选的原生并行工具执行、单工具适用性元数据和按 MCP Server 配置的并发上限。
- 为 OneBot v11 与 NapCat 的 LLM 请求新增可读的 QQ 系统表情上下文。

### 变更

- 将配置偏好访问迁移到异步、非阻塞路径，减少假死和死锁风险。 (#9582, #9584, #9649)
- 使用 favicon 作为插件默认图标，并改善深色主题的文字对比度。 (#9547, #9643)
- 权限包装工具和函数工具执行器现在会保留异步生成器产生的全部结果。
- 并行执行前增加即时权限复核，为每次调用覆盖生命周期 Hook，并对模型可见错误进行脱敏，同时扩展 MCP 结果归一化处理。
- 将本地 Docker 部署重构为独立的 `dev` 和 `runtime` 阶段，固定基础镜像和 Compose 健康检查，并支持通过 `ASTRBOT_FEATURES` 选择运行时功能组。
- 保持 fork 的源码构建 Compose 契约、Python 3.14 基线和当前 Dashboard/API 架构。

### 修复

- 稳定知识库搜索，区分加载失败与空结果，恢复完整检索结果，并在按名称查找知识库时支持 UUID 回退。 (#9577, #9578, #9618, #9636)
- 删除提供商配置后刷新内存状态，并同步 Dashboard 中的插件 Skill 状态。 (#9568, #9596)
- 防止临时项目会话出现在 ChatUI 会话列表中，并恢复缺失的 WebChat 会话。 (#9587, #9607)
- 清理发送给 LLM API 的 MCP 工具名称，并将空配置 Schema 正确视为无配置项。 (#9534, #9619)
- 显式配置的 WebUI 发行文件过期时给出警告。 (#9518)
- 在发布统计前记录 Agent 结束时间，并立即取消已停止的 Agent 运行。 (#9597, #9602)
- Telegram 动态贴纸改用静态缩略图，并将 Telegram 视频留言转换为视频组件。 (#9610, #9627)
- QQ 媒体上传失败时正确向上传递错误，不再静默继续。 (#9644)

### Fork 变更

- 将 Dashboard 长期记忆管理页重构为响应式、跟随主题的数据视图，补齐完整筛选、无障碍操作、加载与空状态，并简化路由层级。
- 新增原生并行工具执行的 Dashboard 控制项和范围化 API，并在执行前复核权限，提供有界并发、有序结果和取消传播。
- 增加原生并行工具执行的回归测试、双语函数调用文档、OpenAPI 定义及生成的 Dashboard API 客户端。
- Compose 宿主机端口默认继续绑定环回地址，并补充显式远程访问说明；删除旧的 `compose-with-shipyard.yml`。

### Fork 差异

- 上游的 AstrBot 桌面端免登录会话（#9585）未纳入，因为本源码构建 fork 不提供该桌面认证界面。
- 未逐字复制上游发布文案和仅适用于上游的产物链接；本 changelog 只描述 fork 中实际存在的功能。

### 维护

- 更新 GitHub Actions 依赖组，完善流水线调度器类型标注，并稳定 OpenAI HTTP 客户端测试。 (#9620, #9621)
- 对 Python、根 npm、Dashboard 和 Docs 依赖执行破坏性升级；同步 Node.js、npm 与 pnpm 工具链声明，并刷新全部权威锁文件。
- 适配 OpenAI 3.0 使用的 `httpx2` 传输层，更新 Chat Completions、Responses、Embedding 与 TTS 提供商，同时保留代理支持和连接错误处理。
