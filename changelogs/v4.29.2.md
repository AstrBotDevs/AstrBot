## [4.29.2] - 2026-10-24

### 新增

- 消息追踪：新增完整的消息、插件、Agent、工具调用及定时任务执行时间线，支持筛选、服务端分页、调用链折叠和 Token 统计。历史记录改用独立 SQLite 数据库，默认保留 7 天、容量目标 80 MB，并支持暂停记录与清理历史。旧 JSONL 文件保留，但不会自动导入。 (#10614)
- 诊断导出：支持从控制台和系统设置导出诊断 ZIP，包含日志、追踪、配置、插件状态和环境信息；支持预设或自定义时间范围，默认脱敏凭据并匿名化公网 IP。 (#10418, #10659)
- 安装脚本：新增多语言安装流程和中国大陆镜像支持。 (#10629)
- 文档：补充 SerpApi 和 DeepSeek Search API 使用指南。 (#10731)

### 修复

- 备份：补全定时任务、持久化文件和相关数据目录的备份与恢复，避免数据遗漏。 (#10644, #10661)
- Gemini：支持模型自定义生成参数，保留显式设置的零值；修复非字符串枚举导致工具 Schema 不兼容的问题。 (#10719, #10635)
- NVIDIA Rerank：保留模型专属 API 端点路径，避免请求错误的通用地址。 (#10732)
- 电脑使用：修复 Shipyard Bay 执行结果的解析，以及 Windows Shell 超时或取消时的子进程清理。 (#10671, #10729)
- WebUI：修复配置刷新后模型元数据丢失、默认聊天模型选择、插件侧栏名称本地化、桌面更新通知和配置模板字段默认值。 (#10522, #10663, #10576, #10622, #10517)
- WebUI：优化配置说明与条件选项显示，修复全屏日志中的 Pip 安装弹窗、日志流连接等待和页面切换后的重复日志，并明确插件筛选范围。 (#10647, #10608, #10666, #10694, #10691)
- 数据库：使用跨数据库兼容的 JSON 查询表达式。 (#10664)
- 依赖：升级 certifi 和 pip。 (#10670)

### 入口与配置调整

- 日志筛选：顶部筛选项 → “筛选”侧栏；自动滚动开关 → 自动跟随底部，在阅读旧日志时保持位置。 (#10614)
- 消息追踪：展开表格行 → 点击记录打开时间线详情；“加载更多” → 服务端分页；独立记录开关 → 工具栏“开始/暂停”按钮。 (#10614)
- 清理入口：“日志与缓存清理” → “日志、缓存与追踪清理”，新增清理追踪历史。 (#10614)
- 诊断导出：“系统设置 → 常规 → 缓存” → “系统设置 → 维护 → 诊断”；控制台也可导出。 (#10659)
- 追踪设置：`trace_log_enable/path/max_mb` 迁移为 `trace_enable`、`trace_db_path/max_mb` 和 `trace_retention_days`；新数据库设置优先。 (#10614)

### Added

- Message tracing: Added execution timelines for messages, plugins, Agents, tools, and scheduled tasks, with filtering, server-side pagination, collapsible call trees, and token statistics. History now uses dedicated SQLite storage with 7-day retention and an 80 MB capacity target by default, plus recording and cleanup controls. Legacy JSONL files are preserved without automatic import. (#10614)
- Diagnostics: Export a ZIP from the console or settings with logs, traces, configuration, plugin status, and environment details. Select a preset or custom time range; credentials are redacted and public IP addresses anonymized by default. (#10418, #10659)
- Installer: Added multilingual setup and mainland China mirrors. (#10629)
- Documentation: Added SerpApi and DeepSeek Search API guides. (#10731)

### Fixed

- Backups: Include scheduled tasks, persistent files, and related data directories in backup and restore operations. (#10644, #10661)
- Gemini: Honor model-specific generation parameters and explicit zero values, and handle non-string enums in tool schemas. (#10719, #10635)
- NVIDIA Rerank: Preserve model-specific endpoint paths instead of substituting a generic endpoint. (#10732)
- Computer use: Parse Shipyard Bay execution envelopes correctly and clean up Windows shell child processes on timeout or cancellation. (#10671, #10729)
- WebUI: Preserve fetched model metadata after configuration refresh; restore default chat model selection; localize plugin sidebar names; fix desktop update notices and template field defaults. (#10522, #10663, #10576, #10622, #10517)
- WebUI: Clarify configuration hints and conditional settings; keep the Pip dialog visible in fullscreen logs; flush log stream headers promptly; prevent duplicate logs after navigation; clarify plugin filter scope. (#10647, #10608, #10666, #10694, #10691)
- Database: Use portable JSON query expressions. (#10664)
- Dependencies: Update certifi and pip. (#10670)

### Navigation and configuration changes

- Log filters: Top-row controls → Filters sidebar. Auto-scroll switch → automatic bottom following that preserves the position when reading older logs. (#10614)
- Trace: Expanded table rows → timeline detail inspector; Load more → server-side pagination; standalone recording switch → toolbar Start/Pause button. (#10614)
- Cleanup: Log & Cache Cleanup → Log, Cache & Trace Cleanup, with trace history cleanup. (#10614)
- Diagnostics: System Settings → General → Cache → System Settings → Maintenance → Diagnostics; export is also available in the console. (#10659)
- Trace settings: Migrate `trace_log_enable/path/max_mb` to `trace_enable`, `trace_db_path/max_mb`, and `trace_retention_days`. New database settings take precedence. (#10614)
