## [4.30.0-beta.2] - 2026-11-26

**本版本为 Beta 测试版，可能存在不稳定或兼容性问题，建议先在测试环境验证。本次涉及对话数据库、Agent 配置和会话设置迁移。升级前请备份数据与配置；回退旧版需同时恢复升级前备份。**

### v4.30.0-beta.1 → v4.30.0-beta.2

本 changelog 保留 beta.1（含 alpha.1）的全部条目，并单列以下更新。历史行为如有变化，以本节说明为准。

#### 兼容性与升级说明

- 交互视图 API 从 `astrbot.api.chatui` 迁至 `astrbot.api.interactive_ui`，插件需更新 `ViewSpec` / `ViewResult` 的导入路径。视图快照和操作回执改存主数据库并纳入备份；仅存于旧 `chatui.db` 的卡片升级后不可用。 (#11380)
- 插件语言查询 `Context.locale(...)` 改为 `await Context.get_locale(...)`，Agent 会话属性 `AgentRun.session` 改为 `await AgentRun.get_session()`。 (#11355)
- QQ 官方适配器移除「主动消息使用 Markdown」平台配置，旧 `use_markdown` 配置键会在加载时删除，主动消息默认使用 Markdown；插件仍可通过 `MessageChain.use_markdown(False)` 强制纯文本。 (#11378)
- 原生子代理历史统一存入 `ConversationStore`。旧历史仍保留在 preferences 中，升级后的原生 runtime 从 `ConversationStore` 恢复子会话；重新打开专用子代理时使用当前专家配置。 (#11364)
- Steering 行为调整：追加指令会中断正在进行的模型生成，并在同一 turn 内带上新输入重新请求模型；若工具已经执行，则等待本批工具结果后处理新指令，替代 beta.1 的工具后台移交行为。 (#11384)

#### 新增与优化

- 新增系统语言设置，位于 **平台与消息 → 通用 → 系统语言**，支持按配置文件和会话选择简体中文或英语；核心提示和内置指令回复随之切换，与 WebUI 语言及模型生成内容独立。 (#11254)
- 侧边栏聊天模式采用桌面双侧栏，保留可动画收起的主导航图标栏。**聊天侧栏 → 返回导航** 移至 **左侧导航栏 → 左箭头**，返回时恢复原页面与导航宽度；会话和项目支持独立折叠，窄屏继续使用单抽屉。 (#11192)
- ChatUI 新增分类错误卡片，展示模型配置、连接及运行错误，并为模型配置问题提供直接配置入口。 (#11259)
- 插件市场支持通过 `market_plugin_id` 和可选 `registry_url` 链接打开安装流程，登录或初始化后继续安装确认，优先使用市场指定下载包，并保留自定义源和风险插件确认。 (#11375)
- 插件可在 `metadata.yaml` 中声明 `category`。市场分类下拉框改为带数量的可展开分类筛选行，无分类时也保留「全部」及插件总数。 (#11094, #11376)
- 新增火山引擎 Embedding 和阶跃星辰（StepFun）TTS 提供商。 (#10886, #11326)
- 支持 Gemini 4 Neon 思考等级；Gemini 3/4 可组合内置工具与函数调用，保留服务端工具结果和思考签名。组合工具能力要求 `google-genai>=1.68.0`。 (#11251, #11078)
- AstrBot 管理员可编辑当前群组内的定时任务。 (#11242)
- `ctx.agent.run_turn()` 新增 `conversation_id` 指定已有对话，旧 `session_id` 参数保留为已弃用别名。 (#11357)
- 交互卡片改为通用 `InteractiveView` 消息组件，修复跨会话投递、重复发送绑定及含分隔符的会话标识处理。 (#11380)

#### 修复

- MCP 支持从损坏会话及初次连接失败中恢复，明确拒绝不支持的 SDK 主版本，并稳健解码子进程标准错误输出。 (#10838, #10825, #10982)

### v4.30.0-beta.1 → v4.30.0-beta.2 (English)

This changelog retains all beta.1 entries, including alpha.1, and lists the new changes below. Where behavior has changed, this section supersedes the historical entries.

#### Compatibility and upgrade notes

- Move interactive view APIs from `astrbot.api.chatui` to `astrbot.api.interactive_ui`; plugins must update their `ViewSpec` / `ViewResult` imports. Store snapshots and action receipts in the main database and include them in backups. Cards stored only in the old `chatui.db` are unavailable after upgrading. (#11380)
- Replace `Context.locale(...)` with `await Context.get_locale(...)` and `AgentRun.session` with `await AgentRun.get_session()`. (#11355)
- Remove the QQ Official platform option for Markdown proactive messages and drop the old `use_markdown` key on load. Proactive messages default to Markdown; plugins can still force plain text with `MessageChain.use_markdown(False)`. (#11378)
- Store native subagent history in `ConversationStore`. Existing history remains in preferences, while the upgraded native runtime restores child sessions from `ConversationStore`. Reopened specialized subagents use the current expert configuration. (#11364)
- Change steering behavior: follow-up input interrupts active model generation and restarts the model request within the same turn. If tools are already executing, wait for that batch to finish before applying the input, replacing beta.1's background tool handoff behavior. (#11384)

#### Features and improvements

- Add **Platforms & Messages → General → System language** for Simplified Chinese or English core messages and built-in command replies, resolved per profile and session independently of WebUI language and model-generated content. (#11254)

Move **Chat sidebar → Back to navigation** to **Left navigation rail → Left arrow**, restoring the previous page and width. - Show categorized ChatUI error cards for model configuration, connection, and execution failures, with a direct configuration action for model setup problems. (#11259)

- Let plugins declare `category` in `metadata.yaml`. Replace the marketplace Category dropdown with an expandable filter row showing counts; keep **All** and the total count visible even when a source has no categories. (#11094, #11376)
- Add Volcengine embedding and StepFun TTS providers. (#10886, #11326)
- Register Gemini 4 Neon thinking levels and support combining Gemini 3/4 built-in tools with function calling, preserving server-side tool results and thought signatures. Combined tools require `google-genai>=1.68.0`. (#11251, #11078)
- Allow AstrBot administrators to edit scheduled tasks in the current group. (#11242)
- Add `conversation_id` to `ctx.agent.run_turn()` to target an existing conversation, retaining `session_id` as a deprecated alias. (#11357)
- Represent interactive cards as portable `InteractiveView` message components and fix cross-conversation delivery, repeated-send bindings, and conversation identifiers containing separators. (#11380)
