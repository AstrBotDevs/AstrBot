## [4.30.0-beta.2] - 2026-11-26

**本版本为 Beta 测试版，可能存在不稳定或兼容性问题，建议先在测试环境验证。本次涉及对话数据库、Agent 配置和会话设置迁移。升级前请备份数据与配置；回退旧版需同时恢复升级前备份。**

### v4.30.0-beta.1 → v4.30.0-beta.2

以下为 beta.1 之后的更新。alpha.1 和 beta.1 的 changelog 请通过文末的 GitHub Release 链接查看。

#### 兼容性与升级说明

- 系统语言查询 `Context.locale(...)` 改为 `await Context.get_locale(...)`，Agent 会话属性 `AgentRun.session` 改为 `await AgentRun.get_session()`。 (#11355)
- Steering 行为调整：追加指令会中断正在进行的模型生成，并在同一 turn 内带上新输入重新请求模型；若工具已经执行，则等待本批工具结果后处理新指令，替代 beta.1 的工具后台移交行为。 (#11384)
- QQ 官方适配器移除「主动消息使用 Markdown」平台配置，旧 `use_markdown` 配置键会在加载时删除，主动消息默认使用 Markdown；插件仍可通过 `MessageChain.use_markdown(False)` 强制纯文本。 (#11378)
- 原生子代理历史统一存入 `ConversationStore`。旧历史仍保留在 preferences 中，升级后的原生 runtime 从 `ConversationStore` 恢复子会话；重新打开专用子代理时使用当前专家配置。 (#11364)
- 交互视图 API 从 beta.1 的 `astrbot.api.chatui` 迁至 `astrbot.api.interactive_ui` (#11380)

#### 新增与优化

- 新增系统语言设置，位于 **平台与消息 → 通用 → 系统语言**，支持按配置文件和会话选择简体中文或英语；核心提示和内置指令回复随之切换，与 WebUI 语言及模型生成内容独立。 (#11254)
- 侧边栏聊天模式采用桌面双侧栏，保留可动画收起的主导航图标栏。**聊天侧栏 → 返回导航** 移至 **左侧导航栏 → 左箭头**，返回时恢复原页面与导航宽度；会话和项目支持独立折叠，窄屏继续使用单抽屉。 (#11192)
- ChatUI 新增分类错误卡片，展示模型配置、连接及运行错误，并为模型配置问题提供直接配置入口。 (#11259)
- 插件市场支持通过 `market_plugin_id` 和可选 `registry_url` 链接打开安装流程，登录或初始化后继续安装确认，优先使用市场指定下载包，并保留自定义源和风险插件确认。 (#11375)
- 插件可在 `metadata.yaml` 中声明 `category`。市场分类下拉框改为带数量的可展开分类筛选行，无分类时也保留「全部」及插件总数。 (#11094, #11376)
- 新增火山引擎 Embedding 和阶跃星辰（StepFun）TTS 提供商。 (#10886, #11326)
- 支持 Gemini 4 Neon 思考等级；Gemini 3/4 可组合内置工具与函数调用，保留服务端工具结果和思考签名。组合工具能力要求 `google-genai>=1.68.0`。 (#11251, #11078)
- AstrBot 管理员可编辑当前群组内的定时任务。 (#11242)
- `ctx.agent.run_turn()` 新增 `conversation_id` 指定已有对话，旧 `session_id` 参数保留为已弃用别名。 (#11357)
- 交互卡片改为通用 `InteractiveView` 消息组件，修复跨会话投递、重复发送绑定及含分隔符的会话标识处理。 (#11380)

#### 修复

- WebChat 每轮回复保存为一条历史记录，修复刷新后气泡拆分、工具调用顺序和耗时错误；未返回结果的工具显示「已中断，结果未知」，连续模型消息正确分段。旧版已拆分的记录不会自动合并。 (#11282)
- 按钮回调数据库读写移至工作线程，避免阻塞各平台事件循环，并清理过期回调；修复分块上传清理产生未等待协程的问题。 (#11282)
- 按完整用户轮次截断上下文，保留相应工具调用与结果、系统消息和当前任务，避免拆断历史。 (#11316)
- 修复子代理在 `skills_like` 模式下拿到不可执行工具的问题，并保留主 Agent 选定的运行时工具。「插件 → 管理行为 → 函数工具」改为仅列出插件工具；运行时工具在配置文件 AI 能力设置中管理，MCP 工具在「插件 → MCP」查看。 (#11335)
- 修复重置会话后重复发送分段回复的问题。 (#11373)
- 保留模型上下文中的 @ 提及信息及引用语音转写，纯 @ 消息也能注入群聊上下文。 (#10992, #11341, #11347)
- 完善 KOOK 媒体消息处理，并将语音卡片交给语音识别。 (#11115, #11307)
- 发送附带说明的附件时保留原文件名。 (#11379)
- 规范 OpenAI 流式工具调用标识，避免分片中的名称或 ID 重复拼接。 (#10703)
- MCP 支持从损坏会话及初次连接失败中恢复，明确拒绝不支持的 SDK 主版本，并稳健解码子进程标准错误输出。 (#10838, #10825, #10982)
- 插件启停时在更新激活状态后解析视图，修复视图状态不同步。 (#11306)
- 指令别名冲突时展示后端具体错误；平台消息高级选项默认折叠；修复 MDI 图标扫描并升级图标字体。 (#11302, #11255, #11193)
- 修复历史追踪状态与标记不一致，以及消息未进入调度器时追踪无法结束的问题；会话等待器提前结束时立即唤醒超时任务。 (#11339, #11342, #11349)

#### 开发与维护

- 合并冒烟和单元测试 CI，将 Windows 测试失败改为阻断；优化登录、路由、缓冲区及事件路由测试，移除冗余测试并修复系统语言改动后的 CI。 (#11226, #11228, #11260, #11263, #11268, #11269, #11270, #11295, #11382)
- 停止跟踪生成的 MDI 字体产物，修复项目许可证和赞助配置格式，更新 GitHub Actions，并移除部分 NapCat 相关界面文案与文档内容。 (#11250, #11262, #11292, #11345, #11312)

**This is a Beta release and may have stability or compatibility issues. Validate it in a test environment first. This release migrates conversation storage, Agent configurations, and session settings. Back up data and configuration before upgrading; downgrading also requires restoring the pre-upgrade backup.**

### v4.30.0-beta.1 → v4.30.0-beta.2 (English)

The following changes were made since beta.1. For the alpha.1 and beta.1 changelogs, follow the GitHub Release links below.

#### Compatibility and upgrade notes

- Replace `Context.locale(...)` with `await Context.get_locale(...)` and `AgentRun.session` with `await AgentRun.get_session()`. (#11355)
- Remove the QQ Official platform option for Markdown proactive messages and drop the old `use_markdown` key on load. Proactive messages default to Markdown; plugins can still force plain text with `MessageChain.use_markdown(False)`. (#11378)
- Store native subagent history in `ConversationStore`. Existing history remains in preferences, while the upgraded native runtime restores child sessions from `ConversationStore`. Reopened specialized subagents use the current expert configuration. (#11364)
- Change steering behavior: follow-up input interrupts active model generation and restarts the model request within the same turn. If tools are already executing, wait for that batch to finish before applying the input, replacing beta.1's background tool handoff behavior. (#11384)
- Move interactive view APIs from `astrbot.api.chatui` to `astrbot.api.interactive_ui` (#11380)

#### Features and improvements

- Add **Platforms & Messages → General → System language** for Simplified Chinese or English core messages and built-in command replies, resolved per profile and session independently of WebUI language and model-generated content. (#11254)
- Add animated desktop dual sidebars in sidebar chat mode, retaining the main navigation as an icon rail. Move **Chat sidebar → Back to navigation** to **Left navigation rail → Left arrow**, restoring the previous page and width. Conversations and projects can collapse independently; narrow screens retain one drawer. (#11192)
- Show categorized ChatUI error cards for model configuration, connection, and execution failures, with a direct configuration action for model setup problems. (#11259)
- Support marketplace installation links using `market_plugin_id` and optional `registry_url`, preserving the flow through login and setup. Prefer marketplace download packages and retain custom-source and risky-plugin confirmations. (#11375)
- Let plugins declare `category` in `metadata.yaml`. Replace the marketplace Category dropdown with an expandable filter row showing counts; keep **All** and the total count visible even when a source has no categories. (#11094, #11376)
- Add Volcengine embedding and StepFun TTS providers. (#10886, #11326)
- Register Gemini 4 Neon thinking levels and support combining Gemini 3/4 built-in tools with function calling, preserving server-side tool results and thought signatures. Combined tools require `google-genai>=1.68.0`. (#11251, #11078)
- Allow AstrBot administrators to edit scheduled tasks in the current group. (#11242)
- Add `conversation_id` to `ctx.agent.run_turn()` to target an existing conversation, retaining `session_id` as a deprecated alias. (#11357)
- Represent interactive cards as portable `InteractiveView` message components and fix cross-conversation delivery, repeated-send bindings, and conversation identifiers containing separators. (#11380)

#### Fixes

- Save each WebChat assistant turn as one history record, fixing split bubbles after reload and tool-call ordering and duration. Mark unfinished calls as **Interrupted, result unknown** and separate consecutive model messages. Previously split records are not merged. (#11282)
- Move button callback database operations to worker threads, clean up expired callbacks, and prevent unawaited chunked-upload cleanup coroutines. (#11282)
- Truncate context by complete user turns, retaining their tool calls and results, leading system messages, and the current task. (#11316)
- Restore executable tools for delegated sessions in `skills_like` mode and preserve the parent's selected runtime tools. **Extensions → Handlers → Function Tools** now lists only plugin tools; manage runtime tools in profile AI capability settings and view MCP tools under **Extensions → MCP Servers**. (#11335)
- Prevent duplicate segmented replies after resetting a conversation. (#11373)
- Preserve mention information and quoted voice transcripts in model context, and inject group context for bare mentions. (#10992, #11341, #11347)
- Improve KOOK media message handling and forward voice cards to speech recognition. (#11115, #11307)
- Preserve attachment filenames when sending captions. (#11379)
- Normalize OpenAI streamed tool-call identities to avoid duplicate names or IDs across chunks. (#10703)
- Recover MCP sessions and initial connections, reject unsupported SDK major versions, and robustly decode subprocess stderr. (#10838, #10825, #10982)
- Resolve plugin views after updating activation state so enabled and disabled views stay consistent. (#11306)
- Show backend details for command alias conflicts, collapse advanced platform message options, and fix MDI icon scanning while upgrading the icon font. (#11302, #11255, #11193)
- Fix trace history state and flags, finish traces for messages dropped before scheduling, and wake timeout tasks immediately when session waiters stop early. (#11339, #11342, #11349)

#### Development and maintenance

- Merge smoke and unit-test CI and make Windows failures blocking. Streamline login, route, buffer, and event-routing tests, remove redundant tests, and fix CI after system-language changes. (#11226, #11228, #11260, #11263, #11268, #11269, #11270, #11295, #11382)
- Stop tracking generated MDI font assets, fix project license and funding configuration formats, update GitHub Actions, and remove NapCat-related UI wording and documentation. (#11250, #11262, #11292, #11345, #11312)
