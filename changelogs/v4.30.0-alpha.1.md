## [4.30.0-alpha.1] - 2026-11-15

### 新增与重构

- 对话存储：迁移至事件日志后端，统一模型上下文、插件消息写入和 WebChat 历史投影，并支持旧数据库及备份转换。 (#10077)
- Agent：统一主 Agent 构建、运行时会话和唤醒执行；提供 `ctx.agent.run_turn()` 等插件接口，完善生命周期事件与子代理结果回传。 (#10934, #10936, #11051, #11052)
- 子代理：支持按配置文件启用通用子代理、选择专用 Agent，并配置并发和超时；运行时不可用的子代理会被跳过。 (#11053, #11128)
- 会话配置：统一配置映射与字段覆盖，支持多会话批量编辑、恢复继承，以及机器人页面中的会话映射管理。 (#11097)
- Windows 沙盒：新增原生 AppContainer 进程沙盒。 (#10466)
- 决策模型：新增 OpenAI Decisions API 提供商。 (#10968)
- 插件：支持可折叠配置分组及 `collapsed` Schema 标记；插件页面桥接可获取主题主色和辅助色及其变更。 (#11067, #11046)
- WebUI：新增总览页面和侧边栏聊天导航，更新图标，并优化滚动条、涟漪动画、聊天标题、菜单及弹窗样式。 (#11100, #11090, #10997, #11102, #11107)

### 优化与修复

- 模型与搜索：网络搜索遇到特定 API Key 错误后继续重试；修复 `text_chat` 最后一次重试成功仍被判为失败的问题；合并 Anthropic 非流式响应中的多个文本块；更新 Gemini TTS 默认模型。 (#10877, #10922, #11057, #10828)
- 平台消息：保留 QQ 按钮回复中的媒体；优化 aiocqhttp 流式分段；Telegram 发送者没有用户名时回退到显示名称；QQ 官方图片上传失败时不再记录图片载荷。 (#10903, #10989, #10715, #10740)
- 内容处理：保留 EPUB 链接中的文字，以及持久化蒙太奇图片对应的动画指导。 (#10794, #10837)
- 插件与日志：SSE 流关闭时通知插件页面；将插件失败日志归属到对应插件；控制台日志时间戳包含日期。 (#10932, #10904, #9617)
- WebUI：修复 Firefox 中 WebChat 滚动跳动，改善窄屏提供商配置布局，保留编辑中的模型预览，并修复长插件指令换行和设置滚动条间距。 (#11036, #10949, #10792, #10860, #11070)
- 配置：说明内置指令对唤醒词的依赖，并调整 AI 能力设置顺序。 (#10861, #11103)
- 开发流程：新增 GitHub Project 交付同步与同步来源追踪，优化全量协调并跳过 fork 同步事件；精简重复测试和 CI 执行，修复本地测试脚本的 `--no-dashboard` 行为。 (#10905, #10909, #10935, #10939, #10941, #10945, #10946, #11005, #11007, #11009)

### 入口与兼容性变更

- 欢迎页 → 总览，原 `/welcome` 地址继续可用。 (#11100)
- 侧边栏 SubAgent 管理 → 配置文件 → AI → 能力 → 子代理 → 配置专用 Agent；原 `/subagent` 地址继续可用。 (#11053)
- 自定义规则 / 会话管理 → 配置文件 → 管理会话配置映射；原 `/session-management` 自动跳转。内置 `/persona` 指令已移除，请在会话映射的覆盖设置中调整人格。 (#11097)
- 旧会话列表、批量提供商及服务更新 API 已移除；客户端应读取活跃 UMO / 配置映射，并通过 `/api/v1/sessions/rules` 提交会话覆盖。详见[会话配置映射指南](https://docs.astrbot.app/use/custom-rules.html)。 (#11097)
- 对话插件接口统一使用 `context.conversations`，`context.conversation_manager` 保留为兼容别名；旧标题和人格更新方法改用 `update_conversation(..., title=...)` 和 `update_conversation(..., persona_id=...)`。`_no_save` 在事件存储中表示不进入后续恢复的上下文，原文仍会持久化。详见[插件 AI 开发指南](https://docs.astrbot.app/dev/star/guides/ai.html)。 (#10077)

### Added and Refactored

- Conversation storage: Migrated to an event-log backend for model context, plugin message writes, and WebChat history projections, with conversion of existing databases and backups. (#10077)
- Agents: Unified main-agent construction, runtime sessions, and wakeup execution; exposed plugin APIs including `ctx.agent.run_turn()` and improved lifecycle events and subagent result delivery. (#10934, #10936, #11051, #11052)
- Subagents: Added profile-scoped generic workers, specialized agent selection, concurrency, and timeout settings; skip subagents whose runtimes are unavailable. (#11053, #11128)
- Session configuration: Unified profile mappings and field overrides, with batch editing, restoration of inherited values, and mapping management on the Bots page. (#11097)
- Windows sandbox: Added a native AppContainer process sandbox. (#10466)
- Decision models: Added an OpenAI Decisions API provider. (#10968)
- Plugins: Added collapsible configuration groups with a `collapsed` schema flag; exposed primary and secondary theme colors and their updates through the plugin page bridge. (#11067, #11046)
- WebUI: Added an Overview page and sidebar chat navigation, refreshed icons, and refined scrollbars, ripple animations, chat titles, menus, and dialogs. (#11100, #11090, #10997, #11102, #11107)

### Improved and Fixed

- Models and search: Retry web searches after key-specific failures; accept successful final `text_chat` retries; concatenate multiple text blocks in non-streaming Anthropic responses; update the default Gemini TTS model. (#10877, #10922, #11057, #10828)
- Platform messages: Preserve media in QQ button replies; segment aiocqhttp streaming replies incrementally; use Telegram display names when usernames are absent; stop logging image payloads on QQ Official upload failures. (#10903, #10989, #10715, #10740)
- Content processing: Preserve inline EPUB link text and animation guidance associated with persistent montage images. (#10794, #10837)
- Plugins and logs: Notify plugin views when SSE streams close; attribute plugin failure logs to their plugins; include dates in console timestamps. (#10932, #10904, #9617)
- WebUI: Fix Firefox WebChat scroll jumps, improve narrow provider dialogs, preserve model previews while editing, wrap long plugin commands, and add settings scrollbar spacing. (#11036, #10949, #10792, #10860, #11070)
- Configuration: Clarify built-in command wake-word requirements and reorder AI capability settings. (#10861, #11103)
- Development: Add GitHub Project delivery synchronization and ancestry tracking, improve full reconciliation, and skip fork sync events; prune duplicate tests and CI runs and honor `--no-dashboard` in local test scripts. (#10905, #10909, #10935, #10939, #10941, #10945, #10946, #11005, #11007, #11009)

### Navigation and Compatibility Changes

- Welcome → Overview; the `/welcome` URL remains available. (#11100)
- Sidebar Subagent Management → Config → AI → Capabilities → Subagents → Configure Specialized Agents; `/subagent` remains available. (#11053)
- Custom Rules / Session Management → Config → Manage session mappings; `/session-management` redirects automatically. The built-in `/persona` command is removed; edit personas through session mapping overrides. (#11097)
- Removed the old session-list, batch-provider, and batch-service APIs. Clients should read active UMOs / mappings and submit session overrides through `/api/v1/sessions/rules`. See the [session mapping guide](https://docs.astrbot.app/en/use/custom-rules.html). (#11097)
- Use `context.conversations` for plugin conversation access; `context.conversation_manager` remains a compatibility alias. Replace the old title and persona update methods with `update_conversation(..., title=...)` and `update_conversation(..., persona_id=...)`. In event storage, `_no_save` excludes content from restored context; the original content is still persisted. See the [plugin AI guide](https://docs.astrbot.app/en/dev/star/guides/ai.html). (#10077)
