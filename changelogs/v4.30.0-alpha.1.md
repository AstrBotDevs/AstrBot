## [4.30.0-alpha.1] - 2026-11-15

**本次涉及对话数据库、Agent 配置和会话设置迁移。升级前请备份数据与配置；回退旧版需同时恢复升级前备份。**

### 主要更新

- 将会话后端迁移到事件溯源方式，减少重复上下文写入和部分写放大，优化存储性能；增量保存消息与工具调用，完善执行中断后的历史处理。 (#10077, #11158, #11162)
- 统一 Agent 运行时，修复定时任务与后台唤醒的回复投递；插件可通过 `ctx.agent.run_turn()` 发起任务、传递 metadata、追加输入并收集待发送结果。 (#10934, #10936, #11052, #11148, #11153)
- 重构子代理为具有独立上下文的后台任务，支持通用与专用 Agent、追加指令和结果回传。入口由侧边栏移至 **配置文件 → AI → 能力 → 子代理**，按配置文件管理。 (#11053)
- 将自定义规则与会话管理统一至 **配置文件 → 管理会话配置映射**，支持基础配置与字段覆盖、批量编辑和恢复继承；模型指令与页面共用同一份设置。 (#11097)
- 新增 Windows AppContainer 本机沙盒，支持工作区隔离、代码执行与联网控制。 (#10466)
- 新增 DeepSeek 语音识别、语音合成及 OpenAI Decisions 判断模型；更新 Gemini TTS 默认模型。 (#11118, #10968, #10828)
- **欢迎页 → 总览**：展示每日用量、系统资源及机器人异常；可选将聊天入口放入侧边栏。升级 Markdown 渲染并按需加载聊天与高亮资源，统一菜单、弹窗和滚动交互。 (#11100, #11090, #11138, #11107)
- 插件配置支持可折叠分组，插件页面可获取主题颜色；重整 AI 开发文档，并补充配置控件示例与截图。 (#11067, #11046, #11154)

### 优化与修复

- 完善运行中追加输入的保存与继续执行；不可用子代理不再阻断主会话，且可取消选择；移除完整工具 Schema 模式下的默认工具调用提示词。 (#11141, #11128, #11147, #11152)
- 修复模型最后一次重试成功仍报错、Anthropic 多文本块丢失，以及搜索密钥失效后未切换其他密钥的问题。 (#10922, #11057, #10877)
- 修复 QQ 按钮回复丢失媒体，避免图片上传失败日志拖慢面板；优化 OneBot 流式分段性能，补全 Telegram 无用户名发送者的昵称。 (#10903, #10740, #10989, #10715)
- 修复 Firefox 聊天滚动跳动、模型预览不一致、EPUB 链接文字丢失和 GIF 历史说明丢失；完善插件错误日志归属、SSE 断开通知及日志日期显示。 (#11036, #10792, #10794, #10837, #10904, #10932, #9617)

**This release migrates conversation storage, Agent configurations, and session settings. Back up data and configuration before upgrading; downgrading also requires restoring the pre-upgrade backup.**

### Highlights

- Migrate conversations to event sourcing, reducing duplicate context writes and some write amplification. Persist messages and tool calls incrementally and improve history handling after interrupted execution. (#10077, #11158, #11162)
- Unify the Agent runtime and fix reply delivery for scheduled and background wakeups. Plugins can use `ctx.agent.run_turn()` to start tasks, pass metadata, add inputs, and collect prepared outputs. (#10934, #10936, #11052, #11148, #11153)
- Rebuild subagents as background tasks with independent context, generic or specialized configurations, follow-up inputs, and result delivery. Move management from the sidebar to **Config → AI → Capabilities → Subagents**, with per-profile settings. (#11053)
- Merge Custom Rules and Session Management into **Config → Manage session mappings**, supporting base profiles, field overrides, batch editing, and restored inheritance. Model commands and the editor share the same settings. (#11097)
- Add a Windows AppContainer sandbox with workspace isolation, code execution, and network controls. (#10466)
- Add DeepSeek speech recognition and synthesis and OpenAI Decisions models; update the default Gemini TTS model. (#11118, #10968, #10828)
- **Welcome → Overview** now shows daily usage, system resources, and bot errors. Add optional sidebar chat navigation, upgrade Markdown rendering, load chat and highlighting assets on demand, and refine menus, dialogs, and scrolling. (#11100, #11090, #11138, #11107)
- Add collapsible plugin configuration groups and theme colors for plugin pages. Reorganize AI development guides and add configuration control examples and screenshots. (#11067, #11046, #11154)

### Improvements and Fixes

- Improve persistence and continuation of inputs added during execution. Unavailable subagents no longer block the main conversation and can be deselected. Remove default tool-call instructions in full-schema mode. (#11141, #11128, #11147, #11152)
- Fix successful final model retries being reported as failures, lost Anthropic text blocks, and search requests failing without trying other configured keys. (#10922, #11057, #10877)
- Preserve media in QQ button replies and prevent oversized image-upload failure logs from slowing the dashboard. Improve OneBot streaming segmentation performance and use Telegram display names when usernames are absent. (#10903, #10740, #10989, #10715)
- Fix Firefox chat scroll jumps, inconsistent model previews, lost EPUB link text, and missing GIF context guidance. Improve plugin error attribution, SSE closure notifications, and dated console logs. (#11036, #10792, #10794, #10837, #10904, #10932, #9617)
