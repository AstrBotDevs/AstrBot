## 4.27.4 - \[WIP\]

### Added

- Display each plugin's last update time in marketplace details, formatted for
  the active Dashboard locale. (#9690)

### Fixed

- Removed the 10-file batch limit for knowledge-base uploads. Uploads now use
  task-specific staging and process files one at a time to avoid retaining a
  whole batch in memory. (#9701, fork adaptation)
- Preserved the Dashboard password across configuration loads when
  `password_change_required` is set, avoiding unexpected password rotation.
  (#9665)
- Separated reasoning metadata from source-backed provider configurations while
  retaining the model metadata catalog. (#9699, fork adaptation)
- Made Trace code-display foreground colors adapt to the active theme. (#9688)

### Documentation

- Added plugin attribution guidance covering acknowledgements, licenses, and
  required copyright notices.

### Fork Adaptations

- Kept the fork's task tracking, cancellation handling, and temporary-file
  cleanup in the knowledge-base upload flow.
- Preserved the fork's Chinese and English locale set while separating provider
  reasoning metadata, and retained the bundled local monospace font in Trace.

### Fork Deviations

- Did not apply the upstream medium-width Chat sidebar change (#9698): the
  fork's existing `hidden-lg-and-up` layout already keeps the sidebar
  accessible at that breakpoint.
