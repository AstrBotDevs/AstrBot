## [4.27.1] - 2026-08-05

### Added

- Added `-y` / `--yes` to `astrbot init` for unattended initialization. (#9514)
- Exposed built-in Skills as lifecycle-owned, read-only presets while allowing local overrides. (#9517)
- Added project-chat placeholders and a persistent bottom composer. (#17333, #07baa)
- Expanded NapCat inbound and forwarded-message parsing, local T2I runtime statistics, compiled command routing, per-plugin log levels, and Telegram partial-reply quotes. (fork commits `9de822cc`, `b8516a46`, `c38f6625`, `b7bd824e`, `b0605928`, `e2aaf622`)

### Changed

- Hardened Dashboard API-key capability boundaries and Bearer-authenticated backup downloads. (#9503, #9525)
- Made generated file artifacts lease-aware, recreated the tool-image cache atomically, and removed the obsolete independent cache cleanup path. (#9506, #9490, #9504)
- Persisted terminal tool history safely, including intermediate tool calls. (#9500)
- Restricted member Skill filesystem writes and kept the built-in Skill catalog owned by the active runtime. (#9517)
- Modernized runtime ownership, bounded background work, provider/adapter lifecycle cleanup, and the Dashboard API surface. (fork commits `708ca085`, `c9c56080`, `e19133fd`, `d8794ba1`, `167f655f`, `c434db76`, `a141974a`, `4ad07e84`)
- Kept the fork's source-build Compose contract and Python 3.14 / Node 26 / pnpm 11 development baseline. (fork commits `7fd3f710`, `630601eb`, `3d2c4769`, `95dc6425`)

### Fixed

- Rejected nonpositive retrieval limits before querying knowledge bases. (#9455, fork adaptation)
- Restored the current favicon on the Dashboard login page. (#9537)
- Stabilized knowledge-base ranking and rerank payloads without adopting the upstream relative-score rewrite. (fork commit `f51ac74a`)
- Preserved streamed WebChat and QQ Official response tails, honored the selected model on regeneration, and fixed plugin-upload hangs. (fork commits `07e37099`, `4e02e3ce`, `2e1c71f3`, `1fc47d44`)
- Resynchronized cron state and localized future task times, bypassed loopback proxy lookups, and updated MiMo TTS and Bailian rerank defaults. (fork commits `2e7c34e8`, `16e37959`, `dcafdcc9`, `7ae03cc5`)
- Hardened lifecycle races, path handling, backup cleanup, provider contracts, error redaction, TLS, XML/HTML parsing, and Windows FAISS paths. (fork commits `6be4f107`, `7f1ad01f`, `bebeb165`, `a4e1e8c2`, `6faeed16`, `513feb52`, `21c11dec`, `ad130af5`, `b1192db8`)

### Maintenance

- Pinned GitHub Actions by commit and refreshed the audited dependency set. (#9532, fork commits `1947ee75`, `3c5f28ac`)
- Performed a breaking dependency refresh across Python, root npm, Dashboard, and Docs; migrated MCP 2.0 transports and updated the affected DashScope, Monaco, and Markdown-It integrations.
- Regenerated the OpenAPI client/public contract and synchronized bilingual documentation for changed Dashboard behavior.

### Fork Deviations

- Removed from the upstream 4.27.0/4.27.1 changelog because they are not present in this fork: group-message history and retrieval (#9465); deprecation decorators and the renamed tool-call helper (#9468, #9469); managed local shell sessions, Windows PowerShell sessions, sender isolation, line writes, and compact shell output (#9470, #9471, #9479, #9501, #9507); document-context embeddings and the relative-score rank-fusion rewrite (#9457, #9455); generic Git plugin updates and the unified extension/persona workspace (#9493, #9499); long-paste attachment conversion and upstream composer styling (#9496); UUID-based transient filenames (#9505); the stateless Responses provider (#9515); office/PDF/Spreadsheet/skill-creator payloads and host conversion (#9517); upstream styling/component removals (#9491, `e4cf9b16`, #9541); Issue Forms and invalid-file-type cleanup (#9536, #9544).
- Upstream release text was not copied verbatim. The fork keeps the `4.27.1` version metadata while retaining its own no-legacy, source-build, security, and Python 3.14-only policies.

## 中文

### 新增

- 为 `astrbot init` 新增 `-y` / `--yes` 选项，支持无人值守初始化。 (#9514)
- 将内置 Skill 暴露为由生命周期管理的只读预置能力，同时允许本地同名覆盖。 (#9517)
- 新增项目聊天占位提示和持久化底部输入区。 (#17333, #07baa)
- 扩展 NapCat 入站及转发消息解析，新增本地 T2I 运行统计、编译式命令路由、插件独立日志级别和 Telegram 部分回复引用。 (fork 提交 `9de822cc`、`b8516a46`、`c38f6625`、`b7bd824e`、`b0605928`、`e2aaf622`)

### 变更

- 加固 Dashboard API Key 权限边界，并支持 Bearer 认证的备份下载。 (#9503, #9525)
- 为生成文件引入租约管理，使工具图片缓存写入具备原子性，并移除旧的独立缓存清理路径。 (#9506, #9490, #9504)
- 安全持久化终端工具历史，包括中间工具调用。 (#9500)
- 限制成员 Skill 的文件系统写入，并由活动运行时管理内置 Skill 目录。 (#9517)
- 现代化运行时所有权、有界后台任务、Provider/适配器生命周期清理和 Dashboard API。 (fork 提交 `708ca085`、`c9c56080`、`e19133fd`、`d8794ba1`、`167f655f`、`c434db76`、`a141974a`、`4ad07e84`)
- 保持 fork 的源码构建 Compose 契约，以及 Python 3.14 / Node 26 / pnpm 11 开发基线。 (fork 提交 `7fd3f710`、`630601eb`、`3d2c4769`、`95dc6425`)

### 修复

- 在查询知识库前拒绝非正数检索限制。 (#9455，fork 适配)
- Dashboard 登录页恢复使用当前 favicon。 (#9537)
- 在不采用上游相对分数重写的前提下，稳定知识库排序和重排序请求。 (fork 提交 `f51ac74a`)
- 保留 WebChat 和 QQ 官方机器人流式响应尾部，重新生成时遵循所选模型，并修复插件上传卡住问题。 (fork 提交 `07e37099`、`4e02e3ce`、`2e1c71f3`、`1fc47d44`)
- 重新同步 Cron 状态并本地化未来任务时间，绕过回环地址代理查询，并更新 MiMo TTS 和 Bailian 重排序默认值。 (fork 提交 `2e7c34e8`、`16e37959`、`dcafdcc9`、`7ae03cc5`)
- 加固生命周期竞态、路径处理、备份清理、Provider 契约、错误脱敏、TLS、XML/HTML 解析和 Windows FAISS 路径。 (fork 提交 `6be4f107`、`7f1ad01f`、`bebeb165`、`a4e1e8c2`、`6faeed16`、`513feb52`、`21c11dec`、`ad130af5`、`b1192db8`)
