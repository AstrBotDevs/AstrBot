# Connecting to bf16.ai

[bf16.ai](https://bf16.ai) is an uncensored LLM API serving open-weight models (DeepSeek V4.1 Flash, GLM-5.3, Kimi K3.1 Pro, and bf16 Auto routers) with 1M context windows, vision, structured tool calling, and ultra-low refusal rates over an OpenAI-compatible endpoint. Because refusal behavior is removed from the model weights rather than papered over with prompts, autonomous AstrBot IM workflows and tool chains complete reliably while your local AstrBot permissions and sandboxes enforce operational boundaries.

## Configuring the Chat Model

1. Register and sign in at [bf16.ai](https://bf16.ai).
2. Create an API key (`sk-bf16-v1-...`) in [Dashboard → API Keys](https://bf16.ai/dashboard/keys).
3. In the AstrBot WebUI, open **Providers → Chat Completion**, click **Add**, and select **`bf16.ai`**.
4. Enter your `API Key`, confirm `API Base URL` is `https://api.bf16.ai/v1`, and click **Save and Fetch Models** (or add a model manually such as `deepseek/deepseek-v4.1-flash-uncensored`, `zai-org/glm-5.3-uncensored`, or `bf16/auto`).
5. Click `+` next to the desired model, enable **Vision** and **Tool Calling** if needed, and click **Test Model** to verify connectivity.

## Applying the Chat Model

Open **Config**, select your profile, go to **AI → Model**, set **Chat Model** to your bf16.ai model, and click **Save Configuration**.
