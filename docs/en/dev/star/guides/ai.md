# AI

AstrBot provides model calls, Agent execution, tools, and conversation APIs for plugins. Choose a guide for your task:

| Guide | Contents |
| --- | --- |
| [Models](./ai/models.md) | Generate replies with chat models and make structured decisions with decision models. |
| [Agents](./ai/agent.md) | Run an Agent in an existing conversation, or build a custom Agent and multi-agent workflow. |
| [Tools](./ai/tools.md) | Define tools and register them with AstrBot. |
| [Sessions and Conversations](./ai/conversations.md) | Understand UMOs and CIDs and read or write conversation history. |
| [Other APIs](./ai/other.md) | Read and manage personas. |
