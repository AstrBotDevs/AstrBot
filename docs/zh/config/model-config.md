# 配置自定义模型参数

可在 WebUI 中配置模型参数：

1. 打开「模型提供商」，选择包含目标模型的提供商。
2. 在「已配置的模型」列表中，点击模型名称或其设置图标，打开模型配置对话框。
3. 直接编辑推理强度、温度、Top-p和输出词元上限，或添加其他请求参数。空白字段中的预设仅供参考，保存时不会写入。
4. 点击「保存」。

可用的字段取决于提供商，具体支持的参数和取值请参考对应提供商的文档。

支持推理强度的模型会先显示「Reasoning Effort」，再显示「模型上下文窗口大小」。

旧入口「模型配置 → 自定义请求体参数 → 修改」已并入模型配置。原生Gemini 3和Gemini 4的推理强度在各模型的「Reasoning Effort」中设置。旧的提供商级「思考级别」已移除，留空或选择`auto`时使用Gemini的模型默认值。
