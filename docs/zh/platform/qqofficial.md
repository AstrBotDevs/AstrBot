# 接入 QQ 官方机器人平台

QQ 官方机器人平台是腾讯官方提供的一个机器人接入平台，允许开发者通过官方接口将机器人接入 QQ 群聊和个人聊天中。

目前主要通过 Webhook 方式接入。

- [Webhook 方式](/platform/qqofficial/webhook)
- [Websockets 方式](/platform/qqofficial/websockets)

## 流式回复

QQ 消息列表私聊（C2C）支持原生流式回复，群聊和频道不支持。开启「流式输出」后，群聊和频道遵循「不支持流式回复的平台」设置：选择「实时分段回复」时，遇到句末标点就发送当前文本，工具状态消息前也会发送尚未结束的文本；选择「关闭流式回复」时，每条完整的模型回复生成后再发送。

「合并 Agent 中间消息」用于非流式模式下将同一轮执行的多条模型回复合并发送，不影响群聊的实时分段回复。Webhook 和 Websockets 接入方式行为一致。
