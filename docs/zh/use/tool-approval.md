# 工具审批与权限档位

可以把某些工具设成“执行前需要人批准”。Agent 想调用它们时，会先向发起这次对话的用户请求批准，用户允许后才执行。ChatUI 另外提供按对话的权限档位，用来在当前对话里收窄访问范围或免去询问。

## 配置需要审批的工具

在配置文件的 AI 设置中（“其他配置”分组，可直接搜索）设置：

| 配置项 | 说明 |
| --- | --- |
| 需要审批的工具（`agent.config.misc.tool_approval.tools`） | 工具名列表，如 `astrbot_execute_shell`、`astrbot_file_write_tool`、`future_task`。留空表示不审批。 |
| 工具审批超时时间（秒）（`agent.config.misc.tool_approval.timeout`） | 默认 120。超时视为未批准，工具不执行。 |

只在使用 AstrBot 内置 Agent 运行器时生效。审批不会放宽任何权限：工具执行时仍受[本机环境](./astrbot-agent-sandbox.md#local-environment)的权限策略限制。

## 批准方式

名单内的工具被调用时，AstrBot 把工具名和完整参数发给发起人，等待回复：

- **ChatUI**：输入框上方出现审批卡片，可选择“允许”“本对话不再询问”或“拒绝”。等待期间，对应的工具卡片显示“等待批准”。处理后，这一行结果（已允许 / 未获批准 / 已过期）收进这轮回复下方的运行详情，和工具调用放在一起；子代理在后台发起的审批也一样。显示的是后端实际的决定：请求已经超时后再点击不会改变结果。
- **其他平台**：发送一条包含参数和四位确认码的消息；支持按钮的平台同时附带“允许”“拒绝”按钮。回复确认码即批准，发送其他内容即取消。

只有发起人本人的回复有效，群聊中其他成员的回复不会被当作答复。参数过长时，文字平台只显示前 1500 个字符并注明未显示的长度；看不到全部内容时请拒绝。超过 100000 个字符的参数不会发起审批，工具直接不执行。

被拒绝、超时或无法发出审批时，模型会收到“工具未执行”的说明，不会自动重试。

## 定时任务

把 `future_task` 加入名单后，创建或修改定时任务需要批准，审批卡片会写明任务名称。批准时也一并批准该任务到点运行时用到的、名单内的其他工具，任务运行时不再逐项询问。具体规则：

- 修改任务只有在本次修改获得批准时才保留这项授权。
- 任务运行时再创建定时任务，仍要批准，授权不会传给新任务。
- 未经批准创建的任务到点运行时调用名单内的工具，会向任务的创建者请求批准；没有记录创建者的任务直接不执行这些工具。
- 定时任务、子 Agent 结果等后台唤醒不会被当作用户对审批的答复。

在其他平台上，定时任务的审批不允许截断参数：参数超过 1500 个字符时不会发起审批。

## ChatUI 权限档位

ChatUI 输入框里加号旁边的按钮显示当前对话的档位（默认“请求批准”），点击后可以切换：

| 档位 | 文件与执行范围 | 审批 |
| --- | --- | --- |
| 工作区 | 角色配置为“整个环境”时收窄为本对话的工作区；Shell 和 Python 需要在进程隔离中运行 | 本机环境下，文件读写、搜索、Shell、Python 工具不再询问；其他名单内的工具照常询问 |
| 请求批准（默认） | 按角色配置 | 名单内的工具每次都询问 |
| 完全访问 | 按角色配置 | 不再询问，`future_task` 的创建和修改除外 |

需要注意：

- **档位只会收窄权限，不会放宽。** 访问范围始终以[本地权限策略](./astrbot-agent-sandbox.md#local-environment)为上限，“完全访问”不会让普通成员获得执行代码或访问整个环境的能力。
- **“工作区”档位与权限策略里的“工作区”文件访问范围不是一回事。** 后者是管理员为角色设定的上限；前者是用户在一个对话里临时选择的更小范围。角色本来就是“工作区”或“关闭”时，选“工作区”档位不会改变访问范围。
- “工作区”档位只在本机运行环境中免去询问；使用第三方沙盒时，名单内的工具照常询问。
- 审批卡片上的“本对话不再询问”批准这次调用，并让当前对话以后不再询问，作用于本轮里排队的工具调用和正在运行的子 Agent。它不会放宽访问范围：在“请求批准”档位下，对话切到“完全访问”；在“工作区”档位下，对话仍限制在工作区、仍在沙盒中执行，档位按钮显示“工作区 · 不再询问”。在菜单里再次选择“工作区”即可恢复询问。这个状态和档位一样按对话保存，删除对话或退出登录时清除；它不会传给定时任务，创建或修改定时任务（`future_task`）仍需批准。
- 切换档位立即生效，本轮后续的工具调用和子 Agent 按新档位执行。
- 分支追问打开时沿用主对话的档位；在分支里点“本对话不再询问”只影响该分支，不影响主对话。
- 在“工作区”档位下创建或修改的定时任务，运行时同样被收窄到工作区。“完全访问”不会传给定时任务：任务到点运行时仍按上面的定时任务规则询问。
- 档位保存在当前浏览器中；后端只在服务运行期间记住它，删除对话或分支时一并清除。

对于 API 调用，聊天请求可以带 `permission_mode`（`workspace`、`ask`、`full`）；`PUT /api/v1/chat/sessions/{session_id}/permission-mode` 用于在一轮回复进行中修改档位，只能修改调用者自己的 WebChat 会话，否则返回 403。
