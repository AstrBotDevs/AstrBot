# AstrBot 知识库

> [!TIP]
> 此页只记录当前 fork 仍支持的现行知识库工作流；旧流程仅保留历史归档，不再作为正式支持路径。

![知识库预览](https://files.astrbot.app/docs/zh/use/image-3.png)

## 配置嵌入模型

打开服务提供商页面，点击新增服务提供商，选择 Embedding。

当前内置的 Embedding 提供商类型包括 OpenAI 兼容服务、Gemini、NVIDIA NIM 和 Ollama。

点击上面的提供商卡片进入配置页面，填写配置。

配置完成后，点击保存。

## 配置重排序模型（可选）

重排序模型可以一定程度上提高最终召回结果的精度。

和嵌入模型的配置类似，打开服务提供商页面，点击新增服务提供商，选择重排序。当前内置的 Reranker 提供商类型包括 vLLM 兼容、Xinference、百炼和 NVIDIA。

## 创建知识库

AstrBot 支持多知识库管理。在聊天时，您可以**自由指定知识库**。

进入知识库页面，点击创建知识库，如下图所示：

![image](https://files.astrbot.app/docs/source/images/knowledge-base/image.png)

填写相关信息。在嵌入模型下拉菜单中您将看到刚刚创建好的嵌入模型和重排序模型（重排序模型可选）。

> [!TIP]
> 一旦选择了一个知识库的嵌入模型，请不要再修改该提供商的**模型**或者**向量维度信息**，否则将**严重影响**该知识库的召回率甚至**报错**。

## 上传文件

创建好知识库之后，可以为知识库上传文档。可以一次选择多个文件，也可以直接拖放或选择整个文件夹（例如一批 Markdown）。嵌套目录会递归收集受支持的文档。每批上传不再限制为最多 10 个文件，单个文件大小不超过 128 MB。

![上传文件](https://files.astrbot.app/docs/zh/use/image-4.png)

## 使用知识库

在配置文件中，可以为不同的配置文件指定不同的知识库。

> [!WARNING]
> 知识库存储是运行目录下的 SQLite 文档库，加上 `data/knowledge_base/` 中的本地 FAISS 索引，属于单进程单机部署。选定嵌入模型后不要改模型或向量维度，否则召回会失败；已有索引不会自动迁移。上传失败会做补偿清理，API 报失败后不应还能检索到半成品文档。NVIDIA 内置默认嵌入或重排模型若有变更，已保存的 provider 配置和已建索引也不会自动迁移。
