# AstrBot Star

在 `3.4.0` 版本之后，AstrBot 将插件命名为 `Star`。AstrBot 是一个高度模块化的项目，通过插件可以发挥这种模块化的能力，实现各种功能。

<span style="color: gray">~~使用 `/plugin` 可以看到所有插件。~~（已归档：`/plugin` 等扩展指令已迁移至 `builtin_commands_extension` 插件，默认不随主程序安装）</span>请在 WebUI 左栏的 `插件` 页面管理插件。

`插件` 页面包含以下标签页：

- `插件`：查看、启用/禁用、更新、卸载已安装的插件，安装本地插件。
- `插件市场`：浏览由 AstrBot Cloud（<https://cloud.astrbot.app>）提供的插件市场，支持按下载量等排序，详情页展示插件更新时间。
- `MCP`：管理 MCP 服务器，详见 [MCP](/use/mcp)。
- `技能`：管理 Skills，详见 [技能 Skills](/use/skills)。
- `管理行为`：集中管理各插件注册的指令与函数工具（指令管理）。

## 安装插件

在 `插件` 页面点击右下角 + 按钮，支持以下安装方式：

- 从插件市场一键安装。
- 填写插件仓库地址，支持 HTTP(S)、SSH、SCP 风格的 Git 仓库（v4.27.0 起）。
- 选择本地目录，安装本地插件（v4.26.3 起）。
- 通过文件上传的方式手动安装插件。

也可以使用 CLI 管理插件，详见 [CLI 指令](/use/cli)。

## 插件管理

- 插件的启用/禁用状态与其注册的 LLM 工具的启用状态相互独立（v4.26.2 起），可在 `管理行为` 标签中逐个控制，并为每个函数工具单独配置使用权限。
- 每个插件可以单独设置日志级别（v4.26.8 起），便于按插件排查问题。
- 插件配置页支持一键恢复默认值（v4.27.3 起）。
- 卸载插件时，会同时清理该插件的 KV 存储数据。

如果想自己开发插件，详见 [几行代码实现一个插件](/dev/star/plugin-new)。
