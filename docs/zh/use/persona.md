# 人格管理

AstrBot 的「人格」（Persona）用于定义机器人的角色设定、系统提示词、预设对话，以及可以使用的工具与技能。人格在 WebUI 的 `人格` 页面中管理，可以创建、编辑、删除，并使用文件夹分类整理。

## 管理人格

进入 WebUI 的 `人格` 页面：

- 点击 `创建人格` 新建人格。
- 在人格卡片上可以查看、编辑、移动或删除人格。
- 使用左侧文件夹树或顶部面包屑在文件夹之间切换，也可以把人格拖动到文件夹中。

## 人格字段

| 字段 | 说明 |
| --- | --- |
| 人格 ID (`persona_id`) | 人格的唯一标识，不能重复 |
| 系统提示词 (`system_prompt`) | 发送给模型的系统提示词，用于设定角色与行为 |
| 预设对话 (`begin_dialogs`) | 可选的预设对话，帮助模型更好地理解角色设定 |
| 工具 / 技能 | 该人格可以使用的工具与技能范围 |

工具与技能的配置说明见 [工具使用 Tools](./function-calling.md) 与 [技能 Skills](./skills.md)。

## 导入人格

在 `人格` 页面右上角的 `…` 菜单中选择 `导入人格`，即可导入 AstrBot 导出的人格 JSON 文件。

导入前会弹出格式说明对话框，也可以参考下面的说明。导入只接受 `.json` 文件，支持的字段如下：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `system_prompt` | 是 | 系统提示词。缺失时导入失败。 |
| `persona_id` | 否 | 人格 ID。缺省为 `imported_persona`。如果该 ID 已存在，会自动追加 `_imported`；仍然冲突时再追加 `_imported_1`、`_imported_2`，以此类推。 |
| `begin_dialogs` | 否 | 预设对话列表，缺省为空数组 `[]`。 |

最小示例：

```json
{
  "persona_id": "my_persona",
  "system_prompt": "You are a helpful assistant.",
  "begin_dialogs": ["Hello", "Hi! How can I help you?"]
}
```

> [!WARNING]
> `tools`（工具）和 `skills`（技能）不会被导入。导入后该人格默认启用全部工具与技能。迁移或备份人格时，需要再次手动配置工具与技能。

## 导出人格

在人格卡片或详情对话框中选择 `导出`，会下载该人格的 JSON 文件。

> [!NOTE]
> 导出同样只包含系统提示词与预设对话，不包含工具与技能配置。
