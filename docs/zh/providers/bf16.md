# 接入 bf16.ai

[bf16.ai](https://bf16.ai) 提供无审查（Uncensored）开源权重模型推理 API（DeepSeek V4.1 Flash、GLM-5.3、Kimi K3.1 Pro 以及 `bf16/auto` 智能路由），兼容 OpenAI 接口，支持 1M 上下文、视觉理解与结构化工具调用。由于模型权重层已去除过度拒答行为，AstrBot 多步自动化任务、技术群聊与 Agent 沙箱工作流不易被误拒中断，同时由 AstrBot 本地权限与沙箱策略守住安全边界。

## 配置对话模型

1. 注册并登录 [bf16.ai](https://bf16.ai)。
2. 在 [控制台 → API Keys](https://bf16.ai/dashboard/keys) 创建 API Key（以 `sk-bf16-v1-` 开头）。
3. 进入 AstrBot WebUI 的「模型提供商」→「对话」，点击「新增」，选择 `bf16.ai`。
4. 填写 `API Key`，确认 `API Base URL` 为 `https://api.bf16.ai/v1`，点击「保存并获取模型」（或手动填写模型 ID，如 `deepseek/deepseek-v4.1-flash-uncensored`、`zai-org/glm-5.3-uncensored`、`bf16/auto`）。
5. 在模型列表中点击所需模型右侧的 `+` 启用，按需开启视觉与工具调用能力，并点击「测试模型」验证连通性。

## 应用对话模型

进入「配置文件」，选择要使用的配置文件，在「AI」→「模型」中将「对话模型」设为刚添加的 bf16.ai 模型，点击右下角「保存配置」。
