# 图片处理

使用内置 Agent 执行器处理新消息时，AstrBot 默认会在发送图片给模型前统一图片格式，减少格式不兼容的问题。处理不会覆盖原图。

## 配置

在管理面板的 **配置文件** 页面搜索 **启用图片压缩**。该选项默认开启，关闭后不再缩放、转码或生成动图拼图。

**最大边长**默认为 1280 像素，静图和动图拼图共用此设置，小图不会放大。

## 处理方式

- **静图**：转换为单帧 PNG，保留显示方向与透明度。
- **动图**：从 GIF、动画 WebP、APNG 等图片中均匀选取最多 9 帧，包含首尾动画帧，生成白底 3×3 PNG 拼图；不足 9 帧的格子留白。单帧 GIF 和静态 WebP 按静图处理。
- **无法读取或解码的图片**：跳过该图片，其他文字和正常图片继续处理。

> [!TIP]
> PNG 文件不一定比原图更小，可通过调整“最大边长”控制图片尺寸。

> [!NOTE]
> 本功能仅适用于经过本地消息流水线的本次输入，包括引用图片。工具回图、第三方 Agent 后端及插件绕过流水线直接调用模型不在处理范围内。会话历史保存模型实际看到的图片内容，不会重新转换旧图片。
