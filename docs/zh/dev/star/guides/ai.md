# AI

AstrBot 为插件提供模型调用、Agent 执行、工具和对话管理接口。根据要完成的任务选择文档：

| 文档 | 内容 |
| --- | --- |
| [模型](./ai/models.md) | 调用对话模型生成回复，使用判断模型进行结构化决策。 |
| [Agent](./ai/agents.md) | 调用现有会话的 Agent，或构建自定义 Agent 与多 Agent 编排。 |
| [工具](./ai/tools.md) | 定义工具并注册到 AstrBot。 |
| [会话与对话](./ai/conversations.md) | 理解 UMO 与 CID，读取和写入对话历史。 |
| [其他](./ai/other.md) | 读取和管理人格。 |
