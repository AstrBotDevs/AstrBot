# 注册、登录与付款

{% hint style="danger" %}
**必须先付款再绑定。** 未开通套餐的用户中心里不会出现「绑定 QQ 机器人」与扫码入口，防止未付费占用托管资源。
{% endhint %}

## 1. 打开用户中心

在浏览器打开管理员配置的 **用户中心** 地址（与 GitBook 教程同域或子域均可，例如 `console.你的域名.com`）。

## 2. 注册账号

- 使用常用邮箱或手机号注册。
- 设置登录密码，完成验证（以实际上线版本为准）。

## 3. 登录并选择套餐

登录后进入 **套餐 / 订阅** 页：

| 常见项 | 说明 |
| :--- | :--- |
| 月付 / 年付 | 含基础托管 + 一定额度 Token |
| 超额 | 超出部分按用户中心展示的用量与系数计费（见 [费用说明](../usage/billing-coefficient.md)） |

完成支付后，账号状态应显示为 **已开通**。

## 4. 付款后才能看到的内容

开通后，用户中心侧边栏会出现例如：

- **绑定 QQ 机器人**（扫码一键创建 / 填写 AppID）
- **我的人设（鱼）**（可选模板或托管方代配）
- **用量与账单**

若仍看不到，请确认支付成功并刷新页面，或查看 [常见问题](../support/faq.md)。
