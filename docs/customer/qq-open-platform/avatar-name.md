# 头像、名称与简介

{% hint style="danger" %}
**创建时把头像选成大肥鱼并填好名称。** 选好后若无法更改图片或名称，请前往 [q.qq.com](https://q.qq.com) 处理。
{% endhint %}

头像与名称都在 **手机 QQ / 微信的创建页** 完成，不在鱼咖用户中心上传。

## 扫码创建时（必做）

以 QQ「创建机器人账号」为例（你截图的那一页）：

1. 点圆形头像 → 上传 **大肥鱼** 图片  
2. **机器人名称**：建议填「大肥鱼」（≤20 字）  
3. **机器人简介**：可选  
4. 勾选「安全使用须知」→ **创建机器人**

微信渠道若出现类似资料页，同样：先换大肥鱼头像，再填名称。

推荐图可在用户中心「接鱼回家」指引里下载，或使用托管方提供的大肥鱼立绘。

## 创建之后还能改什么？

| 项目 | 说明 |
| :--- | :--- |
| 头像 | 改不了则前往 [q.qq.com](https://q.qq.com) |
| 名称 / 简介 | 改不了则前往 [q.qq.com](https://q.qq.com) |
| 对话性格 | 托管侧人格配置，与头像无关，见 [什么是「你的鱼」](../persona/your-fish.md) |

创建时尽量一次选对大肥鱼头像与名称；事后若页面不允许修改，统一到 [q.qq.com](https://q.qq.com) 处理。

## 手机里看到的还是旧企鹅？

- 刚创建后等缓存刷新，或退出资料页再进  
- 确认看的是 **本次扫码创建的那只机器人**，不是别的测试号
