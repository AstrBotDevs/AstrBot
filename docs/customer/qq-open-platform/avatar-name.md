# 修改头像、名称与简介

{% hint style="info" %}
**头像不在 AstrBot WebUI 里改。** 登录 [QQ 开放平台](https://q.qq.com) → 进入你的机器人 → **基础资料 / 机器人信息** 修改。
{% endhint %}

## 可修改项

| 项目 | 在哪里改 | 说明 |
| :--- | :--- | :--- |
| 头像 | 开放平台机器人资料 | 建议 1:1，避免模糊 |
| 名称 | 同上 | 手机 QQ 联系人列表显示的名字 |
| 简介 | 同上 | 资料页短描述 |

修改后若需重新审核，以 QQ 提示为准；审核通过前可能仍显示旧头像。

## 手机 QQ 里看到的不一致？

- 稍等缓存同步，或退出机器人资料页再进入。
- 确认改的是 **已绑定到用户中心的那一个 AppID**，不是别的测试机器人。

## 和「鱼」人格的关系

- **开放平台名称/头像** = 对外壳（像 QQ 昵称）
- **对话性格、口癖、记忆** = 托管方在 AstrBot **人格设定** 里配置，见 [什么是「你的鱼」](../persona/your-fish.md)

两者可以风格统一（都叫大肥鱼、同一张图），但是两套配置。
