# 沙箱、加群与消息范围

## 沙箱

在开放平台 **沙箱配置** 中：

- 添加你的 QQ 号 → 消息列表私聊机器人
- 添加测试群 → 把机器人拉进群（多数情况需你是 **群主**）

沙箱阶段用户数量有限制，适合自测，不代表已对公众开放。

## 添加到群聊（手机 QQ）

1. **联系人 → 机器人** → 你的鱼
2. 资料页下方 **添加到群聊**
3. 选择你是群主的群

## 群消息范围（强烈建议）

进群后：**群设置 → 机器人设置**

| 设置 | 建议 |
| :--- | :--- |
| 机器人可获取的群聊消息范围 | **获取群内全部消息**（否则 @ 才回，体验差） |
| 机器人主动在群聊内发言 | 若需要定时推送/插件主动说话，请开启 |

## IP 白名单（托管方可能要求）

**开发 → 开发设置 → IP 白名单** 填写托管方提供的 **服务器出口 IP**。

不知道 IP 时，在用户中心绑定页或工单里查看说明。未填可能导致机器人连不上腾讯接口。

## 正式对外服务

沙箱测通后，按开放平台指引申请 **正式发布 / 扩大服务范围**（政策以 QQ 当前页面为准）。
