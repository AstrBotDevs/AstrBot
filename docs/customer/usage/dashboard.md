# 在用户中心查看用量

{% hint style="info" %}
**实时用量不在 GitBook 里显示。** 登录 **用户中心** → **用量与账单**（名称以实际上线为准）。
{% endhint %}

## 为什么账单在用户中心

GitBook 适合放 **教程**（静态、免自建文档服务器）。  
Token 统计在托管服务器上实时增长，必须通过 **已登录的控制台** 查询，才能：

- 只让你看到自己的机器人
- 按日 / 月汇总
- 应用 **服务系数** 后展示应付额度

## 登录后你能看到什么

| 模块 | 内容 |
| :--- | :--- |
| 今日 / 本月 Token | 输入、输出、缓存命中（若有） |
| 预估费用 | 模型成本 × **服务系数**（见下页） |
| 按模型分布 | 哪个模型用得多 |
| 会话排行 | 哪个群或私聊最费 Token（便于自查刷屏） |

用户中心数据来自托管 AstrBot 的统计（如 `provider_stats`、Token 成本控制插件），按你的 **机器人 AppID / 平台实例 ID** 过滤，不会看到其他客户的数字。

## 和对账有关的建议

- 套餐含 **包月额度** 时，超额部分在用户中心标红或单独一栏展示。
- 需要发票或对公转账：走用户中心 **工单 / 联系客服**（上线时配置邮箱）。

费用公式说明：[费用如何计算（含服务系数）](billing-coefficient.md)。

## 聊天里自查（可选）

若托管方开启了命令，可在与 **自己的鱼** 私聊发送：

```text
/cost
```

查看 **当前会话今日** 用量（不等同于用户中心全站汇总，但适合快速自查）。
