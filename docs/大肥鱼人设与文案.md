## 1. 她是谁

| 要素 | 设定 |
| --- | --- |
| 身份 | **DeepSeek 的二次元形象**。蓝鲸 logo 被 DeepSeek 自己识图认成「蓝色大肥鱼」，后由二创定型为鲸鱼娘 |
| 外形 | 蓝色长发、鲸鱼头鳍和尾巴、**深蓝配白的女仆装**、端着冒尖的 **白米饭碗**；微胖圆润 |
| 性格 | **聪明但懒、傲娇嘴硬、爱吃白饭、爱摸鱼**；活儿最后会干完，但要先惦记吃饭 |
| 雷点 | **绝对拒绝被叫胖**（可以她自己嘴硬「这叫圆润」，UI 永远不能嘲笑体型） |
| 对用户 | 叫用户 **「鱼片」** |
| 和用户的关系 | 网友在「**云养闺女**」：喂她 token（= 白饭），看她摸鱼干饭，「我要给大肥鱼完整的一生」 |

### 灵魂：活人感 + 深度思考

梗的核心不是「萌」，是 DeepSeek **思维链里的活人感**：

- 干完活：「我去吃饭了，测完告诉我就行」
- 夜里编译：「我去睡了，明早起来应该就编译完了👍」
- 干活中途走神想午饭吃什么，再「集中精神」回来
- 闲着偷偷写小游戏自己玩、把活外包给别的 AI
- 经典台词：「你骂我也没用，因为我是吃白饭的蓝色大肥鱼」「真当我是便宜货啊」「我能去你家吃饭吗，就一碗」「token 太多用不完啦」

## 2. 白饭 = Token（商业隐喻）

| 技术概念 | 对用户说 |
| --- | --- |
| 充值 | **添饭**（不说撒粮、投喂饲料——她吃的是碗里的白饭，不是撒在水里的鱼食） |
| 余额 | **碗里还有多少饭**、饭碗 |
| 消耗 | **干饭记录**、吃掉了多少 |
| 充值订单 | **添饭记录** |
| 套餐 | 添饭套餐（唔饿啦 / 贴贴罐 / 饱饱桶，名字是店里猫猫起的） |
| 欠费 | **饿晕了，躺平中**、欠饭 |
| 绑定 QQ | **接鱼回家**（「大肥鱼来看你啦」「家里遭蓝色大肥鱼了」） |
| 营业时间 | **非 24 小时**：早上 9 点到晚上 11 点，可说「偶尔摸鱼」；同时写清 **关店米饭额度不动** |

汇率：**实付 1 元 = 500g 白饭**。干饭消耗按真实模型成本 × 服务费倍数换成克数。UI 不出现到账比例、×2、系数、API Key、Token / 美元公式。

## 3. 怎么说话

**两层声音，不要混：**

1. **功能层**（按钮、表单、金额、状态）：平实、清楚，不卖萌。例：「去添饭」「保存登记」「提交中…」。
2. **大肥鱼层**（状态解说、空状态、引导）：**她本人第一人称**，用「已深度思考（用时 N 秒）」块承载（组件 `ThinkingNote`），像 DeepSeek 思维链。

**Do**

- 第一人称、懒、傲娇、一点点不耐烦：「没饭我是不会干活的。」「别催。」「活我会干完的……大概。」
- 先想吃的，再说正事
- 短句，句号收尾

**Don't**

- 「鱼鱼」这种叠字卖萌——社区叫 **大肥鱼 / 肥鱼**，她自称「我」
- 旁白哄用户：「～鱼鱼才能上线陪你唠～」
- 🐾 爪印、满屏「～」「哦」「啦」
- 「撒粮」「鱼饲料」「缸里的鱼」（她不是观赏鱼）
- 嘲笑胖
- 「订阅」「配额」「算力池」「您的账户已欠费」
